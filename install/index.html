Precision Feeder

Firmware for the Precision Feeder Rev2 on an ESP32-S3 board.

Install

Plug the board in with a USB cable that carries data, then choose a variant. Chrome or Edge on a computer is needed (Web Serial). After flashing, the installer asks for your Wi-Fi network.

With Bluetooth

Everything, plus the Bluetooth control plane for a PLC or a phone app.

This browser cannot flash: use Chrome or Edge on a computer. Open this page over HTTPS to flash.

Without Bluetooth

Wi-Fi, the web app and Home Assistant only. Smaller, and leaves more memory free.

After installing

  • Open the feeder's address (the installer links to it) to run the setup wizard: name, time zone, board and pins, keys, then calibration.
  • No Wi-Fi yet? The feeder opens its own access point, precision-feeder-xxxxxx-setup, with no password. Join it and the setup page opens. Set an access point password in the wizard.
  • Home Assistant finds the feeder and gives it its key when you adopt it.
  • Later updates: the web app's Diagnostics, "Updates and firmware upload". Your settings and calibration are kept.
